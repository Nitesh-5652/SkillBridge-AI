# SkillBridge AI

> **Bridge Your Skills to Your Dream Career**

SkillBridge AI is an AI-powered Career Intelligence Platform that helps users:

- Analyze resumes
- Improve ATS score
- Identify skill gaps
- Practice AI mock interviews
- Receive AI feedback
- Track interview preparation
- Build personalized learning roadmaps
